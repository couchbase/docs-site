= Get Started with Couchbase

The Developer Data Platform for Critical Applications in Our AI World.

Couchbase is a multipurpose NoSQL platform for operational, analytical, mobile, and AI applications.
Use it fully managed in Capella, or self-manage it in your own environment.


[.centered.card-container]
== Explore the Platform

[.card-box]
=== icon:database[] Run Operational Workloads with Couchbase Server

Use Couchbase Server as a fully managed service in Capella, or deploy it yourself:

* https://cloud.couchbase.com/sign-up[Sign up for Capella^], the fully managed cloud service and the quickest start
* xref:server:install:install-intro.adoc[Install Couchbase Server] to self-manage it in your data center or private cloud
* xref:operator::overview.adoc[Deploy with Couchbase Autonomous Operator] for a self-managed, cloud-native deployment on Kubernetes or OpenShift

Connect your application to Capella or Couchbase Server with the xref:sdk.adoc[Couchbase Operational SDKs].

[.card-box]
=== icon:chart-line[] Run Real-Time Analytics with Operational Insights

Use Operational Insights as a fully managed service in Capella, or deploy it yourself:

* xref:analytics:intro:intro.adoc[Operational Insights Capella], the fully managed analytics database
* xref:enterprise-analytics:intro:intro.adoc[Operational Insights Enterprise], the self-managed analytics database

Connect your application with the Operational Insights SDKs for xref:columnar-sdk.adoc[Capella] or xref:operational-insights-sdk.adoc[Enterprise].


[.card-box]
=== icon:mobile[] Develop for Mobile and the Edge

Sync data from your mobile and edge apps, fully managed in Capella, self-managed in your own data center or at the edge, or directly between devices:

* xref:app-services::index.adoc[Capella App Services], the fully managed sync service
* xref:sync-gateway::introduction.adoc[Sync Gateway], the self-managed sync service for Couchbase Server
* xref:couchbase-edge-server:introduction:intro.adoc[Edge Server], a lightweight database that syncs Couchbase Lite apps in resource-constrained edge environments
* xref:couchbase-lite:android:p2psync-websocket.adoc[Peer-to-peer sync] directly between devices

Build offline-first apps with Couchbase Lite for your platform:

xref:couchbase-lite:android:quickstart.adoc[Android in Java or Kotlin]
| xref:couchbase-lite:swift:quickstart.adoc[iOS Swift]
| xref:couchbase-lite:objc:quickstart.adoc[iOS Objective-C]
| xref:couchbase-lite:c:quickstart.adoc[Edge devices in C]
| xref:couchbase-lite:csharp:quickstart.adoc[C# .NET]
| xref:couchbase-lite:java:quickstart.adoc[Java]
| xref:couchbase-lite-javascript::introduction.adoc[JavaScript]
| xref:cbl-reactnative::intro.adoc[React Native]


[.card-box]
=== icon:stars[] Develop Agentic AI Applications

Build agentic and RAG applications with hosted models, persistent agent memory, Model Context Protocol (MCP) tools, and more:

* xref:ai:get-started:intro.adoc[AI Data Plane], with hosted models, data vectorization, AI Functions, and Agent Catalog
* xref:agent-mem::about-agent-mem.adoc[Agent Memory], a persistent memory layer for agents
* xref:mcp-server:get-started:overview.adoc[MCP Server], to connect AI agents to your Couchbase data

Retrieve relevant context for your AI applications with Hyperscale, Composite, and Search vector indexes in xref:cloud:vector-index:vectors-and-indexes-overview.adoc[Capella] or xref:server:vector-index:vectors-and-indexes-overview.adoc[Couchbase Server].
