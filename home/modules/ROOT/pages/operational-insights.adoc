= Operational Insights

_Formerly Analytics_

*Real-Time Analytics on Your Operational Data — No Pipelines Required.*

[description]
--
Operational Insights is a columnar, MPP-powered analytics engine built directly into the Couchbase platform.
Query your JSON data in place, in real time, with zero-ETL -- no pipelines to build or babysit.
Choose the deployment model that fits your team: fully managed in the cloud, or self-managed on your own infrastructure.
--

[.centered.card-container]
== Choose Your Deployment Model

[.card-box]
=== icon:cloud[] Operational Insights -- Managed

Fully managed, cloud-native Operational Insights, built into the Capella platform.
Spin up a columnar, MPP-powered cluster in minutes -- no infrastructure to provision, patch, or scale yourself.
Connect it straight to your existing Capella data and start running SQL++ over JSON in place.

*Available on:* AWS | GCP

[.card-box]
=== icon:server[] Operational Insights -- Self-managed

The same columnar storage engine, MPP query engine, and SQL++ language, packaged as software you install and operate yourself -- on-premises or in your own cloud VPC.
Full control over infrastructure, networking, and security, with open lakehouse federation via Apache Iceberg.

*Object storage support:* xref:enterprise-analytics:manage:manage-nodes/aws-s3.adoc[AWS S3] | xref:enterprise-analytics:manage:manage-nodes/azure-blob-storage.adoc[Azure Blob] | Google Cloud Storage
