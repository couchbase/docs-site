== SDK APIs to work with Operational Insights Enterprise

Operational Insights SDKs are developed from the ground-up and while they maintain some syntactic similarities with the xref:sdk.adoc[operational SDKs],
they are purpose built for Operational Insights' real-time analytical use cases.
They support streaming APIs to handle large datasets, as well as the common features expected to be present in any modern database SDK --
such as connection management and robust error handling.

Operational Insights is Couchbase’s analytical database. It comes in two deployment options: Operational Insights Enterprise, which you manage yourself, and Operational Insights Capella, which is fully managed. Use the SDK that matches your deployment. The Analytics Service (CBAS) provides row-based analytics inside Couchbase operational clusters. It’s available in self-managed Couchbase Server and in Capella Operational. To query it, use the Operational SDKs.

=== SDK APIs to work with Operational Insights Capella

Operational Insights Capella (formerly Capella Analytics) uses the Columnar SDKs, not the Analytics SDKs.
Operational Insights Capella uses a different connection interface from Operational Insights Enterprise, which connects through a load balancer, so it needs its own SDKs.
The Columnar SDKs are similar to the Analytics SDKs.

=== Row-Based Couchbase Analytics

xref:server:learn:services-and-indexes/services/analytics-service.adoc[CBAS (Couchbase Analytics Service)] is our classic OLAP service, available as part of self-managed Couchbase Server and Capella Operational.
Use the xref:sdk.adoc[operational SDKs] to develop for this service.
